# 海南高考化学真题在线练习平台

一个**纯前端、零后端**的单页练习平台，专为海南省普通高中学业水平选择性考试（新高考）化学真题在线练习设计。

## 功能特性

- **多套试卷、按年份 + 真题N 组织**
  - 顶部「练习试卷」下拉菜单按年份分组：**2024 年（真题1 / 真题2）**、**2025 年（真题1 / 真题2 / 真题3）**、**2026 年（真题1 / 真题2）**，共 7 套练习卷、191 题。
  - 同一年有多份网络搜集的卷子时，分别标为「真题1 / 真题2 …」，下拉即可切换练习。
- **三类题型全覆盖**
  - 单选题
  - 不定项选择题（支持多选后统一提交）
  - 「原为填空题」转化题（把解答题里的填空式设问改造成四选一，界面带专属橙色标签）
- **即时判分交互**
  - 单选题 / 转化题：点击选项立即判定
    - 答对 → 选项变绿，显示「回答正确」
    - 答错 → 选项变红，正确答案高亮为绿色，并给出正确组合（不定项）
  - 不定项选择题：可多选，点「提交」统一判定；**全部选对才算对**，部分选对算错并给出正确组合
- **💡 每题详细解题提示（重点）**
  - **无论作答正确与否，每道题判定后都展示「解题提示」**：点明核心知识点、说明正确选项为何对、错误选项为何错（或常见易错点），数值/计算类附关键步骤，帮助练习者真正学懂弄通。
- **进度与成绩**
  - 实时显示已答/总题数、答对题数、正确率
  - 本卷全部答完弹出得分与正确率汇总
  - 支持按「题型」筛选（单选 / 不定项 / 原为填空题）
  - 「一键重练」清除当前试卷作答状态，重新开始
- **响应式设计**：自适应手机端（触屏友好，选项点击区域 ≥ 48px）与 PC 端
- **数据可维护**：每套试卷一个独立 `data/paper_*.js` 文件，增删试卷/题目只需改对应文件

## 文件说明

| 文件 / 目录 | 作用 |
|------|------|
| `index.html` | 页面结构 + 内嵌样式（CSS），开箱即用 |
| `app.js`     | 全部交互逻辑（试卷切换 / 判分 / 筛选 / 统计 / 解题提示） |
| `data/paper_2024_A.js` 等 7 个 | 各套试卷题库数据，向全局 `window.PAPERS` 注入 |
| `extract_docx.py` | 从 .docx 抽取纯文本的辅助脚本（可选） |
| `README.md`  | 本说明文档 |

> ⚠️ **数据声明（重要）**：7 套试卷均为**从网络下载的练习资料**，并非官方真题，且同一年存在多份内容不同的卷子（已按「真题1 / 真题2 …」区分）。部分题目/答案可能存在瑕疵或事实错误，**请以教材和官方发布为准**。平台价值在于「在线点选作答 + 即时判分 + 详细解题提示」的练习体验。如获得合法授权的真实真题，按下方相同结构新增/替换 `data/paper_*.js` 即可，前端代码无需改动。

## 本地预览

直接双击 `index.html` 用浏览器打开即可使用（数据通过 `<script>` 加载，无需本地服务器）。

若浏览器对本地文件有限制，也可起一个静态服务：

```bash
# 任选其一
python -m http.server 8080
# 或
npx serve .
```

然后访问 `http://localhost:8080`。

## 部署到 GitHub Pages

### 方式一：仓库根目录（最简单）

1. 在 GitHub 新建一个仓库（如 `hainan-chem-practice`）。
2. 把本项目的文件（`index.html`、`app.js`、`README.md` 以及整个 `data/` 目录）提交到仓库**根目录**（`main` 分支）。
3. 进入仓库 **Settings → Pages**。
4. **Build and deployment → Source** 选择 **Deploy from a branch**。
5. **Branch** 选择 `main` 和 `/ (root)`，点击 **Save**。
6. 等待约 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

### 方式二：docs 目录

1. 把 `index.html`、`app.js` 放入仓库内的 `docs/`，`data/` 目录一并放入 `docs/data/`。
2. 注意 `index.html` 中 `<script src="data/paper_*.js">` 的相对路径需与 `docs/` 下结构一致。
3. Pages 的 **Branch** 选择 `main` 和 `/docs`。

### 更新题库

编辑 `data/` 下对应试卷文件后重新 `git push`，GitHub Pages 会在数分钟内自动更新，无需任何构建步骤。新增一套卷子：复制一个 `paper_XXXX.js`，改 `id / year / version / source` 与题目，再在 `index.html` 末尾加一行 `<script src="data/paper_XXXX.js"></script>` 即可。

### 自定义域名（可选）

在 **Settings → Pages → Custom domain** 填入你的域名，并按提示在 DNS 添加 `CNAME` 记录即可。

## 填空题 → 选择题 转化规则（已在题库中落实）

1. 将原填空题干改写为选择题干，**保留题目信息与上下文**；
2. 正确选项 = 原标准答案，再生成 **3 个贴近常见易错点** 的合理干扰项；
3. **数值型填空**的选项必须带单位（如 `0.5 mol`、`4.25 g`、`pH=13`）；
4. 每道转化题在数据中设置 `originalType: "填空题"`，界面自动显示「原为填空题」标签。

## 题目字段速查（data/paper_*.js）

```js
window.PAPERS = window.PAPERS || [];
window.PAPERS.push({
  id: "2025-C",                 // 试卷唯一标识（年份+版本字母）
  year: 2025,
  version: "真题3",             // 同一年多份时：真题1 / 真题2 …
  source: "2025年海南高考化学试卷附答案.docx",
  single: [
    {
      id: "2025C-S1",           // 题目唯一标识
      stem: "题干……",          // 题干文本
      options: ["A. …","B. …","C. …","D. …"],  // 恰好 4 项，带字母前缀
      answer: 0,                // 单选/转化：正确选项索引(0起)
      hint: "解题提示：……"       // 必填，详细解析（知识点+对错分析+易错点）
    }
  ],
  multiple: [ /* 同上，answer 为索引数组如 [0,2]，hint 必填 */ ],
  converted: [ /* 同上，额外 originalType:"填空题" */ ]
});
```
