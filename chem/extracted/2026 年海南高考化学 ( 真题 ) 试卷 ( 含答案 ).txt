2026 年海南高考化学 ( 真题 ) 试卷 ( 含答案 )
考试时间： 75 分钟   满分： 100 分
一、选择题（ 35 题）
(1)  下列物质中，属于单质的是
A.  氧化钠
B.  氧气
C.  氢氧化钠
D.  碳酸钠
答案：  B
解析：   氧气是一种由氧元素组成的单质，而其他选项均为化合物。
(2)  下列反应中，属于置换反应的是
A. Fe + CuSO₄ → FeSO₄ + Cu
B. Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑
C. 2H₂ + O₂ → 2H₂O
D. NaOH + HCl → NaCl + H₂O
答案：  A
解析：   置换反应是单质与化合物反应生成另一种单质和另一种化合物的反应。选项 A 符合置换反应的特征。
(3)  下列物质中，能导电的是
A. NaCl 固体
B. NaCl 溶液
C. NaCl 熔融态
D. NaCl 气体
答案：  B
解析：  NaCl 溶液中含有自由移动的离子，故能导电；而固体、气体和熔融态的 NaCl 在特定条件下导电，但选项 B 是最常见和典型的导电例子。
(4)  下列物质中，属于强电解质的是
A. CH₃COOH
B. NH₃
C. Na₂CO₃
D. H₂O
答案：  C
解析：  Na₂CO₃ 在水溶液中完全电离，属于强电解质；而 CH₃COOH 为弱酸， NH₃ 为弱碱， H₂O 为弱电解质。
(5)  下列关于阿伏加德罗常数（ Nₐ ）的说法不正确的是
A. Nₐ = 6.02×10²³ mol⁻¹
B. Nₐ  是  1 mol  任何物质所含的微粒数
C. Nₐ  是  1 mol  氦气所含的原子数
D. Nₐ  是  1 mol  物质的量单位
答案：  D
解析：   阿伏加德罗常数是一个确定的物理常数，表示 1 mol 任何物质所包含的微粒数，而不是一个单位。
(6)  下列反应中，需要催化剂的是
A. 2H₂ + O₂ → 2H₂O
B. Na₂O₂ + CO₂ → 2NaCO₃
C. 2SO₂ + O₂ ⇌ 2SO₃
D. Fe₂O₃ + 3CO → 2Fe + 3CO₂
答案：  C
解析：  2SO₂ + O₂ ⇌ 2SO₃  是工业制硫酸中的关键反应，通常需要催化剂（如 V₂O₅ ）来加快反应速率。
(7)  下列说法中，错误的是
A.  金属单质在反应中通常作还原剂
B.  氧化还原反应的实质是电子的转移
C.  酸碱反应一定是中和反应
D.  电解质是指在水溶液中或熔融状态下能够导电的化合物
答案：  C
解析：   酸碱反应不一定是中和反应，例如酸与金属氧化物的反应也属于酸碱反应。
(8)  下列说法中，正确的是
A.  离子化合物在固态时不导电
B.  共价化合物在液态时一定导电
C.  共价化合物在固态时一定导电
D.  所有离子化合物在液态时都导电
答案：  A
解析：   离子化合物在固态时离子不能自由移动，因此不导电；在液态（熔融态）或水溶液中可以导电。
(9)  下列物质中，属于强酸的是
A. CH₃COOH
B. H₂CO₃
C. HCl
D. H₂O
答案：  C
解析：  HCl 是强酸，在水溶液中完全电离；而 CH₃COOH 、 H₂CO₃ 均为弱酸， H₂O 为极弱电解质。
(10)  下列关于反应热的说法正确的是
A.  反应热是反应物与生成物的总能量之差
B.  反应热仅指放热反应的能量变化
C.  反应热是反应过程中体系吸收或释放的热量
D.  反应热与反应的条件无关
答案：  C
解析：   反应热是指反应过程中体系吸收或释放的热量，与反应的条件相关。
(11)  下列说法正确的是
A.  化学反应速率与反应物浓度成正比
B.  化学反应速率总是随温度升高而增大
C.  压强对固体和液体的反应速率没有影响
D.  催化剂能改变反应的活化能，从而改变反应速率
答案：  D
解析：   催化剂通过降低活化能加快反应速率，但不影响反应的热效应。
(12)  下列关于勒夏特列原理的表述正确的是
A.  增加浓度，将使平衡向生成物方向移动
B.  增加温度，将使平衡向放热方向移动
C.  增加压强，将使平衡向分子数减少的方向移动
D.  在恒温恒压下，增加惰性气体不会影响平衡移动
答案：  C
解析：   勒夏特列原理指出，当系统处于动态平衡时，若改变条件，系统将向抵消该改变的方向移动。增加压强，平衡会向分子数减少的方向移动。
(13)  下列物质中，属于弱电解质的是
A. Na₂CO₃
B. NaOH
C. CH₃COOH
D. H₂SO₄
答案：  C
解析：  CH₃COOH 是弱酸，部分电离，属于弱电解质；而 Na₂CO₃ 、 NaOH 、 H₂SO₄ 均为强电解质。
(14)  下列关于离子反应的说法不正确的是
A.  离子反应发生在溶液中
B.  离子反应的实质是离子的重新组合
C.  所有复分解反应都是离子反应
D.  离子反应中所有反应物都必须是离子化合物
答案：  D
解析：   离子反应可以发生在溶液中或熔融状态下，且反应物可以是酸、碱或盐，不一定全是离子化合物。
(15)  下列不属于化学性质的是
A.  铁在潮湿空气中生锈
B.  食盐溶解于水
C.  硫酸与碳酸钙反应生成二氧化碳
D.  钠在氧气中燃烧生成氧化钠
答案：  B
解析：   食盐溶解于水是物理性质，不涉及物质的化学变化。
(16)  下列说法错误的是
A.  电解质的质量与溶液的导电性成正比
B.  非电解质的溶液不能导电
C.  离子化合物在熔融状态下能导电
D.  共价化合物的溶液导电性可能较弱
答案：  A
解析：   溶液的导电性不仅取决于电解质的质量，还取决于其浓度和电离程度。
(17)  下列关于化学计量的说法错误的是
A. 1mol 水分子的质量为 18g
B. 1mol 氢气的体积为 22.4L
C. 1mol 任何气体在标准状况下体积都为 22.4L
D.  质量守恒定律是化学计量计算的依据
答案：  B
解析：  1mol 氢气在标准状况下体积为 22.4L ，而 1mol 水分子的质量是 18g 。但 B 选项不正确，因为氢气的物质的量在标准状况下为 1mol 时体积为 22.4L ，但未说明条件。
(18)  下列关于电解质的判断正确的是
A.  盐酸是强电解质
B.  氨水是强电解质
C.  乙醇是强电解质
D.  硫酸是弱电解质
答案：  A
解析：   盐酸完全电离，属于强电解质；而氨水、乙醇均未完全电离，属于弱电解质或非电解质；硫酸为强酸，是强电解质。
(19)  下列说法正确的是
A.  所有金属单质都能与酸反应生成氢气
B.  非金属单质通常为共价化合物
C.  二氧化硫具有漂白性
D.  氢氧化钠溶液显酸性
答案：  C
解析：   二氧化硫具有漂白性，但仅限于某些特定条件；金属单质不一定都与酸反应生成氢气，如铜不与稀硫酸反应；氢氧化钠溶液显碱性。
(20)  下列物质中，属于氧化物的是
A. NaCl
B. CO₂
C. CH₃COOH
D. H₂SO₄
答案：  B
解析：  CO₂ 是由两种元素组成的化合物，且含有氧元素，属于氧化物；其他选项均为其他类型的化合物。
(21)  下列关于化学反应的判断正确的是
A.  氧化还原反应中，一定有电子的转移
B.  分解反应一定有单质生成
C.  置换反应一定有单质参与
D.  复分解反应一定有沉淀生成
答案：  A
解析：   氧化还原反应的本质是电子的转移；分解反应可能生成单质，但不一定；置换反应一定有单质参与；复分解反应可能生成沉淀，但不一定。
(22)  下列关于化学键的说法正确的是
A.  共价键是由原子间转移电子形成的
B.  离子键是由原子间共享电子形成的
C.  共价键的键长越短，键能越小
D.  共价键的形成是原子通过共享电子对来达到稳定结构
答案：  D
解析：   共价键是原子间共享电子对形成的化学键，目的是达到稳定结构；而离子键是由电子转移形成的。
(23)  下列属于弱电解质的是
A.  盐酸
B.  硫酸
C.  碳酸
D.  硝酸
答案：  C
解析：   碳酸在水溶液中部分电离，属于弱电解质；而盐酸、硫酸、硝酸均为强酸，属于强电解质。
(24)  下列关于原电池的说法错误的是
A.  原电池是将化学能转化为电能的装置
B.  原电池中，阳极发生氧化反应
C.  原电池中，电子由负极流向正极
D.  原电池中，电流方向是从正极流向负极
答案：  C
解析：   电子从负极流向正极，而电流方向是从正极流向负极。
(25)  下列离子反应的书写正确的是
A. CaCO₃ + 2HCl → Ca²⁺ + CO₂↑ + H₂O + 2Cl⁻
B. Fe + Cu²⁺ → Fe²⁺ + Cu
C. AgNO₃ + NaCl → AgCl↓ + Na⁺ + NO₃⁻
D. H₂O ⇌ H⁺ + OH⁻
答案：  B
解析：  B 选项正确书写了离子反应式；而 A 、 C 未正确写出离子形式； D 选项应为 H₂O ⇌ H⁺ + OH⁻ ，但选项 D 只是描述了水的电离，未写出完整的反应式。
(26)  下列关于元素周期表中元素性质递变规律的说法正确的是
A.  在同一周期，原子半径随原子序数增大而增大
B.  在同一主族，金属性随原子序数增大而增强
C.  电负性在同一周期内从左到右逐渐增强
D.  在同一主族，非金属性随原子序数增大而增强
答案：  C
解析：   在同一周期内，原子半径随原子序数增大而减小；电负性随原子序数增大而增强；在同一主族中，金属性随原子序数增大而增强。
(27)  下列关于氧化还原反应的判断正确的是
A.  氧化剂被还原
B.  还原剂被氧化
C.  氧化还原反应中，一定有电子的转移
D.  所有置换反应都是氧化还原反应
答案：  D
解析：   置换反应中，单质发生反应，属于氧化还原反应；而氧化剂被还原，还原剂被氧化，电子的转移是其本质。
(28)  下列溶液中， pH 为 7 的是
A. NaCl 溶液
B. CH₃COOH 溶液
C. Na₂CO₃ 溶液
D. NaOH 溶液
答案：  A
解析：  NaCl 溶液为中性； CH₃COOH 和 Na₂CO₃ 分别为弱酸和弱碱的盐，溶液显酸性或碱性； NaOH 为强碱，溶液显碱性。
(29)  下列反应中，属于吸热反应的是
A.  燃烧反应
B.  中和反应
C.  溶解过程
D.  酸碱反应
答案：  C
解析：   溶解过程可能吸热，如硝酸铵溶解吸热；而燃烧、中和及酸碱反应通常为放热反应。
(30)  下列关于化学反应速率的说法正确的是
A.  增大固体物质的表面积，反应速率不变
B.  反应速率与反应物的浓度无关
C.  使用催化剂，反应速率加快
D.  温度降低，反应速率加快
答案：  C
解析：   增大固体物质的表面积可以加快反应速率；反应速率与反应物的浓度有关；使用催化剂可以加快反应速率；温度降低则反应速率减小。
(31)  下列关于反应方向的说法错误的是
A. ΔH < 0  且  ΔS < 0  的反应可能在低温自发进行
B. ΔH > 0  且  ΔS < 0  的反应通常不会自发进行
C. ΔS  的大小主要取决于系统混乱度的变化
D. ΔG = ΔH - TΔS  可用于判断反应的自发性
答案：  B
解析：  ΔH > 0  且  ΔS < 0  的反应通常不会自发进行，尤其是在任何温度下。
(32)  下列关于氢键的描述正确的是
A.  氢键存在于非极性分子之间
B.  氢键是一种特殊的共价键
C.  氢键存在于水分子之间
D.  氢键的能量比共价键小
答案：  C
解析：   氢键存在于水分子之间，属于分子间作用力；氢键的能量比共价键小；且氢键存在于极性分子如水、醇等之间。
(33)  下列有关离子化合物的说法错误的是
A.  离子化合物通常熔点较高
B.  离子化合物在固态时不导电
C.  离子化合物易溶于水
D.  离子化合物由离子构成
答案：  C
解析：   离子化合物的溶解性取决于其性质，如 NaCl 易溶于水；而 BaSO₄ 等离子化合物难溶于水。
(34)  下列关于物质分类的说法正确的是
A.  氧气属于混合物
B.  水属于单质
C.  水属于氧化物
D.  氧气属于化合物
答案：  C
解析：   氧气（ O₂ ）为单质；水（ H₂O ）为氧化物；氧气不属于化合物。
(35)  下列物质中，含有共价键的是
A. NaCl
B. MgO
C. H₂O
D. NaOH
答案：  C
解析：  H₂O 中含有共价键；而 NaCl 、 MgO 为离子化合物； NaOH 中含有离子键和共价键。

三、实验综合题（ 2 题）
(40)  下列关于实验操作的说法错误的是

A.  滴定前需用待测液润洗锥形瓶

五、有机化学推断题（ 2 题）

B.  苯
C.  乙烯

解析：   苯分子中含有苯环结构，属于芳香烃；而其他选项均为脂肪族化合物。
