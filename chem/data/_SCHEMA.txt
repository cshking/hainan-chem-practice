============================================================
海南高考化学真题练习平台 —— 试卷数据文件规范（必读）
============================================================
每个试卷输出【一个独立 .js 文件】，不要写 JSON 文件。

【文件模板】（严格照此，只改内容）
------------------------------------------------------------
window.PAPERS = window.PAPERS || [];
window.PAPERS.push({
  id: "2024-A",
  year: 2024,
  version: "真题1",
  source: "2024年海南省化学高考试卷及解答参考.docx",
  single: [ /* 单选题数组 */ ],
  multiple: [ /* 不定项/多选题数组，answer 为索引数组 */ ],
  converted: [ /* 由填空题改写的选择题，每项须含 originalType:"填空题" */ ]
});
------------------------------------------------------------

【题目对象字段】
  id         : 唯一字符串，格式 = 年份+版本字母+类型字母+序号
              例: "2024A-S1"(单选) "2024A-M1"(多选) "2024A-C1"(转化)
  stem       : 题干文本（保留原题信息；若原题把选项写在题干里，请
              把选项单独拆到 options，题干只留问题）
  options    : 长度为 4 的数组，每个元素是字符串，
              必须带字母前缀，格式统一为 "A. xxx" "B. xxx" "C. xxx" "D. xxx"
  answer     : single/converted 为整数 0-3（对应 options 下标）
              multiple 为索引数组，如 [0,2] 表示 A、C 都选才对
  hint       : 字符串，详细解题提示（必填，要求见下）
  originalType : 仅 converted 需要，固定写 "填空题"

【解题提示 hint 写作要求（每题必写，不可空）】
  面向高中生的详细解析，30–150 字，至少包含：
  ① 考查的核心知识点（一句话点明）；
  ② 为什么正确选项对（关键推理/计算步骤）；
  ③ 错误选项为何错，或常见易错点提醒；
  ④ 数值/单位类务必给出关键计算式。
  用中文，通俗准确；不要用“略”“详见教材”等空话。

【填空题 → 选择题 转化规则（converted）】
  - 将原填空题干改写为选择题干，保留题目信息与上下文；
  - 正确选项 = 原标准答案；再生成 3 个合理干扰项（贴近常见易错点）；
  - 数值型填空（密度、质量分数、pH、浓度等）选项必须带单位；
  - 每项 originalType 固定写 "填空题"；
  - 选项仍写 4 项、带 "A. " 前缀。

【录入范围（重要）】
  只录入能改造为“四选一/多选”的题型：单选题、多选题(不定项)、
  以及可自然改写为四选一的填空题。
  下列【不录入】：纯判断题（除非能自然改四选一）、简答题、讨论题、
  开放性解答题、纯计算大题（若原卷已给四选一选项的按选择录入）；
  若某题在源文档中答案缺失/留空，跳过该题并在返回说明里标注。

【格式铁律（避免 JS 语法错误）】
  - 字符串一律用双引号 "..."；内部如有双引号写成 \"
  - 换行用 \n，不要真的换行；禁止使用反引号 ` 模板字符串
  - options 必须恰好 4 项；answer 索引必须在 0–3 范围内
  - 不要引入任何外部变量或函数；只做 window.PAPERS.push({...})

【完成校验】
  写完文件后，运行：
  node --check <你的文件.js>
  必须无报错。再运行结构自检：
  node -e "global.window={};require('<绝对路径>');const p=window.PAPERS[window.PAPERS.length-1];let e=0;['single','multiple','converted'].forEach(t=>(p[t]||[]).forEach(q=>{if(q.options.length!==4)e++;if(t==='multiple'){if(!Array.isArray(q.answer))e++;}else{if(typeof q.answer!=='number'||q.answer<0||q.answer>3)e++;}if(!q.hint)e++;if(t==='converted'&&q.originalType!=='填空题')e++;}));console.log(e===0?'OK':'ERR'+e);"
  输出 OK 才算完成。
